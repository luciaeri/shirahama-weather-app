# shirahama-weather-app

このお天気アプリは、Gemini（antigravity 環境）によって自動生成されたコードです。 

**自分の実績（ポートフォリオ）ではなく、コードの確認や学習用のリポジトリとして公開しています。**

---

## 概要
- 旧南紀白浜空港を対象とした、1 分ごとに更新され、最大 3 時間先まで 1 分単位で予測できる局所的高性能天気予報アプリです。
- 静的 Web アプリとして構成され、`index.html`, `style.css`, `app.js` などのファイルで構成されています。
- オープンソースであり、自由にコピー・改変・再配布が可能です（MIT ライセンス等をご希望であれば別途設定してください）。

## 主な機能
- 1 分ごとのリアルタイム更新
- 3 時間先までの予測グラフ表示
- ランウェイ方向と風向きの可視化
- Canvas による天候エフェクト

## 使用技術
- HTML / CSS（Glassmorphism デザイン）
- JavaScript (Chart.js, Lucide icons)
- Open‑Meteo API（天気データ取得）

## ローカルでの実行方法
```powershell
# 依存が無いので、static server で起動可能
npm install -g http-server   # まだインストールしていなければ
cd path\to\shirahama-weather-app
http-server .
```
ブラウザで表示されたローカル URL にアクセスしてください。
